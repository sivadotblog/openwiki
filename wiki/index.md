# Data Platform Team Wiki

How the data platform is built and operated: Databricks, Snowflake, Airflow, Prefect,
Bigeye, runbooks, datasets, and onboarding. An agent keeps this wiki in sync with the
platform repos and catalog exports. Every factual statement is a claim tied to a source
version, so changes in the sources show up as stale pages in the next update PR.

Start with [New engineer onboarding](onboarding/new-engineer.md) or [On-call](runbooks/oncall.md).
The rules the agent follows are in [the charter](INSTRUCTIONS.md).
